Мини-приложение бота "СКФУ События" для управления мероприятиями в MAX 

Репозиторий бота: https://github.com/Qwerty000101/qwerty000101.github.io

Сетевой адрес мини-приложения: https://qwerty000101.github.io/

Внимание: полная функциональность доступна только при входе через мессенджер MAX. При открытии в браузере без MAX Bridge используется тестовый профиль администратора для демонстрации интерфейса.

Основные возможности мини-приложения:

- Просмотр афиши мероприятий с фильтрами по категориям и институтам, поиск по названию

- Регистрация на мероприятия и отмена регистрации прямо с карточки события

- Отображение активных билетов с QR-кодами и возможность их удаления

- Создание новых мероприятий через полноэкранную форму (для администраторов)

- Редактирование и удаление существующих мероприятий (для администраторов)

- Просмотр статистики мероприятия: количество зарегистрированных, пришедших, свободные места

- Список участников с поиском по ФИО и экспорт в XLSX

- Встроенный сканер билетов для организаторов: сканирование QR-кода камерой.

- Профиль пользователя с отображением ФИО, института, группы и роли

- Редактирование профиля: смена института, роли (студент/администратор (для тестов), группы

- Автоматическая активация вкладки «Сканер» и кнопки «Добавить мероприятие» для администраторов

Роли пользователей:

  Студент — просмотр афиши, регистрация на мероприятия, управление билетами, просмотр профиля

  Администратор — все возможности студента, а также создание, редактирование и удаление мероприятий, просмотр статистики и списков участников, экспорт отчётов, сканирование билетов

Стек технологий:

React 

MAX-UI (библиотека компонентов для интерфейсов в MAX)

MAX Bridge (для взаимодействия с платформой MAX)

Axios для HTTP-запросов к API бота

QRCode для генерации QR-кодов билетов на клиенте

GitHub Pages для хостинга

Как запустить мини-приложение:

Установите Node.js версии 18 или выше

Клонируйте репозиторий

Перейдите в корневую папку мини-приложения (где находится package.json)

Выполните npm install

Создайте файл .env (или отредактируйте существующий) и укажите адрес API бота: REACT_APP_API_URL=https://ваш-сервер:3000/api (для локальной разработки можно использовать http://localhost:3000/api)

Запустите приложение командой npm start

Приложение откроется в браузере на порту 3001 (или 3000, если свободен)

Как задеплоить на GitHub Pages:

Убедитесь, что в package.json поле homepage указывает на ваш GitHub Pages URL (например, https://qwerty000101.github.io/)

Выполните npm run deploy

После успешного деплоя приложение будет доступно по указанному URL

Примечание: для связи мини-приложения с ботом необходимо, чтобы API бота было доступно по HTTPS. Если бот запущен локально, используйте туннели (например, xTunnel или ngrok) для получения публичного HTTPS-адреса и укажите его в REACT_APP_API_URL перед сборкой.
